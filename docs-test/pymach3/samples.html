Sample handlers#

This module evaluates the likelihood of an experimental model at different parameter values, given your data.

Implement a sample handler derived from pyMaCh3._pyMaCh3.samples.SampleHandlerBase for the event samples in your experiment. The underlying C++ classes SampleHandlerBase and SampleHandlerInterface describe the framework’s sample-handling interfaces. Although the C++ and Python method names differ, the same analysis concepts apply.

API reference#

This is a Python binding of MaCh3s C++ based samples library.

The Sum(w_{i}^2) (sum of weights squared) in the bin, which is sigma^2_{MC stats}
