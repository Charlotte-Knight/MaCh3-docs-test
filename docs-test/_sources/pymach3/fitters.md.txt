# Fitters

This module contains MaCh3's available fitting algorithms. You can also derive
from {py:class}`pyMaCh3._pyMaCh3.fitters.FitterBase` to implement a custom
fitter. See {cpp:class}`FitterBase` for the underlying C++ interface.
