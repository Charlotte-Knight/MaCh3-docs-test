virtual void CalcSplineWeights() final#

CPU based code which eval weight for each spline.

Splines are stored using a flat monolithic structure. The monolith is organised as follows: 

Spline 0
Segment 0: [ Y | B | C | D ]
Segment 1: [ Y | B | C | D ]
Segment 2: [ Y | B | C | D ]

Spline 1
Segment 0: [ Y | B | C | D ]
Segment 1: [ Y | B | C | D ]
Segment 2: [ Y | B | C | D ]

Spline 2
Segment 0: [ Y | B | C | D ]
Segment 1: [ Y | B | C | D ]
Segment 2: [ Y | B | C | D ]
  ...

Once coefficient are grabbed we calculate weight using: 

weight = Y + B*dx + C*dx^2 + D*dx^3;
