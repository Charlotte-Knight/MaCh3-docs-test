Plotting#

The plotting module produces plots from MaCh3 outputs and supports comparing results with other fitters. The Doxygen plotting guide describes the plotting configuration.

pyMaCh3._pyMaCh3.plotting.PlottingManager provides high-level access to the plotting library:

import sys
from pyMaCh3 import plotting

man = plotting.PlottingManager()
man.parse_inputs(sys.argv)

# Use the manager to construct your plots.

The corresponding C++ class is M3::Plotting::PlottingManager.

API reference#

This is a Python binding of MaCh3s C++ based plotting library.
