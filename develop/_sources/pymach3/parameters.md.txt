# Parameters

This module contains the parameter handlers MaCh3 uses for systematic
parameters. You can derive from
{py:class}`pyMaCh3._pyMaCh3.parameters.ParameterHandlerBase` to implement a
custom handler, or use
{py:class}`pyMaCh3._pyMaCh3.parameters.ParameterHandlerGeneric`.

See {cpp:class}`ParameterHandlerBase` and
{cpp:class}`ParameterHandlerGeneric` for the underlying C++ interfaces.
