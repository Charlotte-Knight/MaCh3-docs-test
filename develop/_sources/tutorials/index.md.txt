# Tutorials

The hands-on MaCh3 tutorial is maintained in the
[MaCh3Tutorial repository](https://github.com/mach3-software/MaCh3Tutorial).
It walks through running MCMC, configuring analyses, processing chains, making
diagnostic plots, and developing systematic uncertainties and samples.

See the rendered [MaCh3 Tutorial](https://mach3-software.github.io/MaCh3Tutorial/)
or clone the repository and follow its README to build and run the examples.

Python-binding documentation is not part of this site yet.
