# MaCh3 documentation

MaCh3 is a Bayesian neutrino oscillation fitter. Explore the guides to learn
about the framework, follow a hands-on tutorial, or look up the C++ and Python
APIs.

::::{grid} 1 1 2 2
:gutter: 4
:class-container: mach3-home-grid

:::{grid-item-card} User guide
:link: user-guide/index
:link-type: doc

{material-outlined}`menu_book;3em;sd-text-primary`

Learn the framework's core concepts, configure analyses, and run MaCh3.
Find guidance on Bayesian fitting, MCMC diagnostics, and computing environments.

:::

:::{grid-item-card} Tutorials
:link: tutorials/index
:link-type: doc

{material-outlined}`school;3em;sd-text-primary`

Get started with hands-on examples from the MaCh3 tutorial, from running your
first fit to developing samples and systematic uncertainties.

:::
