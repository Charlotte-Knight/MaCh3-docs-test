Detailed Description
--------------------

This file includes macros and enums for defining spline coefficients. It is designed to be compatible with older CUDA versions, so be cautious when adding new features or including other headers.

KS: Please add stuff here with super caution. This header is being added to gpuSplineUtils.cu. Right now we support most of CUDA even super old. If you add some header with fancy templates it will not compile for older CUDA. This header is a way to use common macros or Enum in CPU and GPU code. For more sophisticated structs please use :ref:`file_Splines_SplineStructs.h`
