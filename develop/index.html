MaCh3 Documentation#

MaCh3 is a Bayesian neutrino oscillation fitter. This site brings together its user guide, tutorials, and generated C++ and Python API references.

Use the user guide to learn about MCMC, fitting, and analysis workflows. The tutorials page links to the hands-on MaCh3 tutorial. The C++ API reference is generated from the public headers and their Doxygen comments.

The API is also linked from the guide; for example, see ParameterHandlerGeneric and ParameterHandlerBase::GetNumParams().
