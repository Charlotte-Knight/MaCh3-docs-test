# User Guide

Welcome to the **MaCh3 User Guide**!

Hover over User Guide to unroll more options and learn basics about MCMC.

## Table of Contents

The guide pages are listed in the navigation. Start with the [FAQ](faq.md),
then read about [Bayesian analysis](bayesian-analysis.md) and
[MCMC convergence](mcmc-convergence.md).

The C++ API is available for further detail on
{cpp:class}`ParameterHandlerGeneric` and
{cpp:func}`ParameterHandlerBase::GetNumParams`. For overloaded methods, include
the parameter types in the C++ domain role, as explained in the
[documentation build guide](../README.md).
